AGGIES Lab Website

AI for Government, Grid, Infrastructure & Engineering Security
[Department of Computer Science]([url](https://engineering.tamu.edu/cse/index.html)) | [College of Engineering]([url](https://engineering.tamu.edu/)) | Texas A&M University
This repository contains the source code for https://www.aggieslab.org/, the official website of the AGGIES Lab at Texas A&M University, led by Professor Shreyas Kumar. The site highlights the lab’s mission, members, research projects, recent events, and publications.

Feel free to view the website [here]([url](https://www.aggieslab.org/)).

Structure

Home: Main page of the lab<br>
Members: Faculty, students, and affiliates<br>
Alumni: Recent graduates<br>
Collaborations: Internal and external collaborations<br>
Advisory Board: Mentors and advisors<br> 
Research: Funding grans and research highlights<br>
Publications: Ongoing and published work<br>
Success Stories: Recent events and socials<br>
Serving Texas: State research contributions<br>
Millionaire By Graduation: AGGIES Lab startup incubator<br>
Cyber Resources: Links to learn more<br>
Contact Us: Communication details<br>
